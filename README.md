# python-libraries-implemented-in-c
This project explores how Python libraries use compiled C code to improve performance. Although Python is known for being easy to read and write, some complex operations can be much faster when implemented in a lower-level language such as C.

I explored how Python can call C functions using ctypes, how shared libraries work, and how libraries such as NumPy use compiled implementations to efficiently process large amounts of data.

Topics 

Calling C from Python: How Python can execute functions written in C using ctypes.
Shared Libraries: How C code can be compiled into a library that Python can load.
How NumPy Works: How NumPy uses compiled code to perform operations on arrays efficiently.
Performance: Why compiled implementations can outperform equivalent Python-level loops.
C Extensions: Why Python libraries sometimes use C for performance-critical operations.
